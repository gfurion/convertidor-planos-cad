PLAN PARA SUBIR A GITHUB
========================

1. Crear cuenta en GitHub (si no tienes):
   https://github.com/signup

2. Descargar e instalar Git:
   https://git-scm.com/downloads/win
   (siguiente, siguiente, siguiente...)

3. Crear archivo .gitignore en la carpeta del proyecto:
   convertidor.exe
   build/
   dist/
   __pycache__/
   *.spec
   ODA/

4. Crear requirements.txt con:
   ttkbootstrap
   pyinstaller

5. Abrir PowerShell y ejecutar:

   cd "C:\Users\gvalbuena\Desktop\Convertidor de Planos CAD"
   git init
   git add .
   git commit -m "Primer commit"

6. Ir a GitHub, crear nuevo repositorio (NO marcar "Initialize with README")

7. Conectar y subir:

   git remote add origin https://github.com/TU-USUARIO/NOMBRE-REPO.git
   git branch -M main
   git push -u origin main

8. El convertidor.exe NO se sube a Git (pesa 82 MB).
   En vez de eso, en GitHub ve a "Releases" > "Create a new release"
   y allí adjunta el .exe como archivo descargable.

FIN
